## 产品检查

按 Wechill QA 模板核对范围、角色、分类、会话状态、权限与重要通知、异常、配置开关、旧版本、三语言候选、埋点和验收。

- 「全部」为本房完整可见集合；「聊天 / 礼物」为其子集；治理限制同时作用于所有视图。
- 进房 / 普通播报留在全部；关键通知独立承载；礼物列表筛选不改交易和动画。
- 录屏观察与新增建议分别标识；默认、记忆、提醒、重连等未写成竞品事实。
- 无虚构效果目标、开发人日或上线日期；真实能力不足时先核查再补接口。

## 已实际验证

在本地浏览器操作模拟原型，检查可见结果；不是只检查源码。

| 项目 | 结果 |
|---|---|
| 三 Tab 切换 | 全部含普通动态、对话、礼物；聊天过滤进房和礼物；礼物显示礼物记录 |
| 新消息点 | 聊天视图添加礼物后礼物亮点，看到礼物记录后清点；当前已见事件不重复提醒 |
| 阅读历史 | 增加多条消息后回到列表顶部，新消息到达保持 scrollTop=0；出现新消息按钮；点击后跳底并清对应提醒 |
| 展开 / 收起 | 按钮切换公屏面积，保留当前 Tab，麦位区可恢复 |
| 跨 Tab 重要提示 | 在礼物视图更新提示，固定提示可见；切 Tab 不丢失 |
| 输入 | 从礼物输入时切到聊天，模拟发送成功，输入清空且无真实外部请求 |
| 断线 | 保留已有缓存和 Tab，显示连接状态并禁用发送；恢复后仍保留当前选项 |
| 加载失败 | 公屏内显示重试按钮；重试恢复缓存 |
| 空态 | 清空模拟数据后礼物显示空态；输入 / 礼物入口保留 |
| 切房 | 房间 ID 改变，默认全部并清除旧会话的筛选与阅读状态 |
| 响应式 | 1100px 桌面及 320px 窄屏；窄屏内三个 Tab、输入及展开入口可用，DOM 测量无横向溢出 |
| 阿语 RTL | Tab 语义顺序按方向排列，消息和输入右对齐，阿语文字及昵称混排可见 |
| 静态资源与语法 | JavaScript 语法通过，HTML 相对链接存在，无外部图片或 CDN 依赖；浏览器未发现页面 error / warn |
