## 使用边界

每个 ZIP 只有一个原始 RP，解压后保留原始文件名，内容 SHA-256 已逐一核对。使用同代或兼容版本 Axure 打开；RP 11 工程不能用低版本直接打开。

本目录保存用户指定快照，未合并或覆盖原型中的规则。SABA、Hlah、ME及历史工程均为参考资料；CP 的 v1.0/v2.0是各工程原名，不自动代表当前 PRD 版本。业务当前口径请返回[Hoki 当前资料索引](../PROJECT_INDEX.md)，或对应模块的当前 PRD。

检索范围为文件名、人工分类/关键词和从 RP 工程元数据提取的页面/目录名称；不等同于所有元件文字的全文搜索，不包含无法从图片读取的文字。工程中的“最新版本”“作废”“不做”“暂缓”等原名称原样保留，只是来源标签。

文件超过 Git 普通文件上限或体积较大，因此二进制统一放在本仓库 Release 附件区，由 Hoki 目录中的本索引连接。未增加付费存储，也未更改仓库可见性。
