## Chrome 后台实操经验（2026-11-12）

- 优先复用用户已授权的浏览器和目标标签页；标签页失效时重新列出当前标签页，不沿用旧 tab ID。索引和页面结构均为临时状态，不写死复用。
- 使用当次工具提供的文档。CUA 上传成功方式是先等待 `filechooser` 事件，再点击上传控件，再用 chooser 的 `setFiles` 选择绝对路径文件；不要把它混同于 Harness 的 API。
- ElementPlus 的透明 checkbox input 曾导致 Playwright click/check/setChecked 超时；本页面用新鲜 AX 索引点击 checkbox 成功，并以勾选值确认。
- 数字字段填写后需失焦，避免界面显示了数字但表单模型尚未更新。填写权重和有效天数后均检查实际值。
- 替换已有上传资源时先显示预览操作层，再点击该字段的删除操作，随后上传替换文件；这是编辑表单内的资源引用替换，不是删除整个资源记录。
- SPA 的 AX / DOM 名称曾短暂保留旧值；以当前实际文本与已保存记录为准。超时先检查页面是否已保存，避免重复创建。
- 奖励包有两层保存：内层资源“确认”后，必须提交外层奖励包“确认”。两个弹窗都叫“编辑”时，先检查作用域再定位按钮；内层关闭后动态的 `last()` 会指向外层，不能继续用它等待“内层隐藏”。
- 奖励包列表“内容”里的 ID 是奖励条目 ID，不能当成光圈资源 ID；资源 ID 应从奖励包编辑页的“资源 ID”列核对。
- 用户对明确授权的命名、上传和配置不希望反复确认；涉及缺失业务参数时询问。此次用户明确选择数量 1、有效期 30 天；这是本次任务口径，不自动推广到其他奖励包。
