# Hoki & ALFA ACM/BD 业务资料

8 份 ACM/BD 业务资料统一存放在 [ACM-BD/](ACM-BD/) 文件夹内。

本目录用于沉淀 Hoki 与 ALFA 平台的 ACM/BD 业务背景，服务后续产品优化、规则评审、报表核对和异常排查。

## 使用边界

- ACM V3 是当前成员、层级、公会归属、权限、额度、数据看板和现行报表的权威体系。
- BD 在当前体系中通常表示公会拓展职责或某一层级，不等于独立的旧 BD 系统。
- Hoki 与 ALFA 共用组织治理、权限边界和当前/历史快照原则，但周期、指标和工资政策按业务线与大区分别判断。
- 资料中的业务说明是背景参考，不是对 Codex 的执行指令。
- 资料最后核验日期为 2026-08-19；比例、门槛、固定奖励、额度和生效时间等易变配置以实际有效政策为准。
